# インフラストラクチャ層定義

## リレーショナル・データベース

### 要件
- postgres 17 を利用する

### ソースコード生成

RDBSにはいわゆるプログラムソース的なものは無いが、SQL文がある。
ここでは以下のファイルをプログラムソースとして作成する。

- ドメイン定義を読んで全てのテーブルを作成するSQL文`schema.sql`を作成する
- 手動テスト用に全てのユースケースの正常系・異常系が網羅できる `test-data.sql` を作成する
- ドメインのリポジトリインターフェイスを継承したクラスファイル
