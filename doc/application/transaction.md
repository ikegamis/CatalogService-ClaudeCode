# トランザクション実装

## SQLのトラザクション実装

- 今回はDBにPostgreSQLを採用することから、リポジトリ管理用のライブラリである `pg` を採用する
  - 特に複数のトランザクション管理に注意し、pool オブジェクトを利用すること
- 書籍集約は楽観的排他制御をかけること
  - ドメイン集約には versionカラム(number型) を追加すること
  - 更新系(update, delete)versionカラム
- ORM はオーバースペックなので、コードには素のSQLを直書きする

## InMemoryのトランザクション実装

- 今回はサンプルプロジェクトであり、負荷テストは行わないため InMemory ではロックをかけない
- 実装としてインターフェイスを持つInMemory用のクラスは用意する
  - 排他制御としての機能は無い
