# コンテキストマップ

## 1. モデル領域

本システムでは`Book`と`Review`の2つの集約モデルを扱う。

## 2. 集約間の関係

- Book は書籍情報を管理する。
- Review は1つの BookId を保持し、対象書籍を識別する。
- Book 1件に対して Review は 0件以上存在する。
- Review が Book 集約全体を保持するのではなく、BookId で参照する。

## 3. 書籍推薦におけるデータ利用

書籍推薦は、対象 BookId に紐づく複数の Review を取得して集計する。元資料では、この処理が複数集約からのデータ取得・集計を必要とすると説明されている。

具体的な Repository の分割、前提書籍名から Book を特定する方法、集計結果をどの形式で返すかは仮決めしている。これらを実装時に推測で確定してはならない。

## 4. 未確定事項

- Book と Review が同一 Bounded Context に属するか、別々の Bounded Context に属するか。
- 別コンテキストとする場合の上流・下流関係、公開言語、同期／非同期連携方式。
- Book の削除・非公開化が存在する場合、関連 Review をどう扱うか。
- Review の登録・変更・削除を行うユースケースと、その認可主体。
