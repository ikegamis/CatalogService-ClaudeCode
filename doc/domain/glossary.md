# 用語集

| 用語 | 定義 |
|---|---|
| カタログ | 書籍と、その書籍に紐づくレビューを扱うモデル領域の呼称。正式な Bounded Context 名かは未確定。 |
| 書籍（Book） | 書籍ID、タイトル、著者、価格を持つ集約。 |
| 書籍ID（BookId） | 書籍を識別する値。元定義では ISBN コードを適用する。 |
| レビュー（Review） | 1冊の書籍に対する投稿者名、評価、コメントを持つ集約。 |
| レビューID（ReviewId） | レビューを一意に識別する値。 |
| 投稿者名（Name） | レビューに表示・記録する投稿者名。 |
| 評価（Rating） | 1〜5の整数値による書籍評価。 |
| コメント（Comment） | レビュー本文。品質評価および前提書籍抽出の入力となる。 |
| 品質係数（Quality Factor） | Rating または Comment の内容を 0.0〜1.0 に正規化・評価した値。 |
| 信頼性（Trustworthiness） | Rating と Comment の品質を組み合わせ、閾値と比較して判定するレビューの性質。具体的な合成式は未確定。 |
| 前提書籍 | 対象書籍を理解するために必要な基礎知識・前提条件として、レビューコメント中で言及される書籍。 |
| 書籍推薦 | 対象書籍のレビューから信頼できるレビューを選び、前提書籍の言及頻度を集計して推薦候補を作る機能。 |
| ISBN-13 | 元定義が BookId に適用するとしている ISBN コード。桁構成・チェックデジット検証の詳細は未確定事項を参照。 |
